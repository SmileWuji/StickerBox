# Example: buffer-triage

Generated by `scripts/make_skill_examples.py` from `commands.sh`, run inside a copy of
`before/`. Paths are relative to that folder; long lists are cut to three entries.

A triage session over a buffer before its images expire. Run from inside a copy of before/: buffer/ holds three images from a chat, stickers/ is a sticker box and gallery/ a gallery.

First read the three README.md files: the buffer keeps images for 60 minutes; the sticker box takes 512 px WEBP or WEBM only and needs text, note, licence and an emotion tag; the gallery takes anything and needs only a licence. List the buffer. With no words the newest come first; the last ones expire soonest.

```sh
$ sticker-box search --box buffer --limit 50 --json
```

Look at each image (the `file` path) and decide. The oldest: a laughing orange face with tears and "LOL". Someone would send it in a chat, so it is a sticker. Stage it into the sticker box.

```sh
$ sticker-box stage --from buffer e26ecca836fc --box stickers --json
```

The newest: a dark, blurred photo, sent by accident. Nothing to keep, so do nothing; it expires on schedule. Moving copies: the buffer's own copies expire too.

*40 minutes later.*

Every buffer image is now past its expiry. `clean` removes them (never `--auto-cleanup` during triage: it removes the oldest images, which are the ones not looked at yet).

```sh
$ sticker-box clean --box buffer --json
```
