# Example: add-stickers

Generated by `scripts/make_skill_examples.py` from `commands.sh`, run inside a copy of
`before/`. Paths are relative to that folder; long lists are cut to three entries.

Add three stickers to a new sticker box and leave out one that breaks its file rules. Run from inside a copy of before/: the box is stickers/, the new files are in inbox/.

First read stickers/README.md. This telegram-sticker box needs `text`, `note` and `license` on every image and at least one `emotion` tag. Its vocabulary is open and still empty, so every tag is new and needs a definition. Stage the first file. Nothing is stored yet; the answer lists what `commit` will need, the OCR hint (often wrong) and any file problems or look-alikes (none here).

```sh
$ sticker-box stage inbox/ok.webp --box stickers --json
```
